# Invitation au mariage de Raphaël & Charline — jusqu'au vin d'honneur

Site de l'invitation du 16 janvier 2027 pour les invités de la journée :
cérémonie civile, cérémonie religieuse, goûter et vin d'honneur. La soirée
n'apparaît pas sur cette version.

## Contenu

- `index.html` — la page unique, CSS et JavaScript inclus, sans dépendance externe
- `assets/` — signature manuscrite et illustrations extraites en SVG depuis les
  faire-part d'origine, polices en woff2
- `robots.txt` — interdit l'indexation par les moteurs de recherche

## Notes

La page fonctionne hors ligne : toutes les polices et images sont locales.
Les textes reprennent mot pour mot le faire-part papier, l'année 2026 ayant été
ajoutée à la date limite de réponse (« vendredi 16 octobre 2026 »).

Les boutons « Itinéraire » ouvrent Google Maps, les boutons « Calendrier »
téléchargent un fichier `.ics` au fuseau Europe/Paris. Les heures de fin des
deux cérémonies sont des estimations : le faire-part n'indique que les heures de
début, sauf pour le goûter et vin d'honneur (15h-18h).

La version complète, avec la soirée, est dans un dépôt séparé :
`invitation_mariage_RC`.
